# 📚 AI Tutor for Slow Learners

An AI-powered personalized tutor designed specifically for slow learners. Built with Python, Streamlit, and Google Gemini AI.

![Python](https://img.shields.io/badge/Python-3.10-blue)
![Streamlit](https://img.shields.io/badge/Streamlit-1.58-red)
![Gemini](https://img.shields.io/badge/Gemini-2.5_Flash-orange)

## 🌟 Features

- 🎤 **Voice Input** - Speak your doubts in Tamil/English
- 🔊 **Voice Output** - Listen to AI explanations
- 📊 **Progress Tracker** - Points, badges, and subject tracking
- 🎮 **Quiz Mode** - MCQ questions with scoring
- 📚 **Multi-Subject** - 6 subjects supported

## 🛠️ Tech Stack

- **Language:** Python 3.10
- **UI Framework:** Streamlit
- **AI Model:** Google Gemini 2.5 Flash (FREE)
- **Voice:** SpeechRecognition + gTTS
- **Data Storage:** JSON
